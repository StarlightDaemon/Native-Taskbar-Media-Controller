# docs/

Navigation guide for this directory.

## audit-reports/

Audit report markdown files, one per audit cycle. Filename encodes the audit date
and the commit SHA that was current at time of audit (e.g.
`audit-2026-05-25-c1fb551.md`).

## fork-reports/

Fork synthesis report (`synthesis-2026-05-19.md`) and individual fork review
documents, one per reviewed fork. Research material only — no redistributed source
code is included.

## prompts/

Archived implementation and research prompts from the v1.0–v1.4 development cycle.
Historical record of the handoffs and scoping documents used during that period;
not active handoffs.
